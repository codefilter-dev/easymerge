# Quickstart

## 1. Install the GitHub App

Open [EasyMerge](https://app.easymerge.dev), then install the GitHub App for your personal account or organisation. Select the repositories that EasyMerge should review.

## 2. Open a pull request

Create a pull request as usual. EasyMerge begins reviewing it automatically when it is opened and whenever you push a new commit.

## 3. Read the review

Open the pull request on GitHub. EasyMerge posts actionable findings as inline comments and reports its status in the pull request checks list. Resolve the finding, discuss it, or mark it as addressed according to your team's process.

## Example

```text
1. Create branch: fix/payment-validation
2. Push the branch and open a pull request
3. Wait for the EasyMerge Review check
4. Read inline findings and update the pull request if needed
5. Merge when the team is satisfied
```

For detailed installation and configuration instructions, see the [EasyMerge documentation](https://easymerge.dev/docs/getting-started/quickstart).
